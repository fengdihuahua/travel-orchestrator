# 文案写作规范（去 AI 味）

这份文件管的是**方案里所有给人看的字**：行程描述、美食推荐、专项说明、踩坑提示、
待办清单、README 和交付说明。

旅行方案的文案只有一个标准：**用户读完知道该干什么。**
达不到这个标准的好句子，都是废句子。

---

## 一、硬禁用词表

看见就换，不要犹豫。

| 禁用 | 为什么 | 换成 |
|---|---|---|
| 值得一提的是 / 值得注意的是 | 废话开场，删掉不影响意思 | 直接说那件事 |
| 首先 / 其次 / 再次 / 最后 | 八股骨架，方案不是论文 | 用时间、地点、因果连接 |
| 总的来说 / 综上所述 / 由此可见 | 无信息量的收尾 | 直接给结论或删掉 |
| 不仅……而且…… | 排比腔 | 拆成两句 |
| 打造 / 赋能 / 助力 / 闭环 / 抓手 | 汇报体 | 说具体动作 |
| 旨在 / 致力于 / 力求 | 官腔 | 删掉，直接做 |
| 丰富多样 / 应有尽有 / 琳琅满目 | 等于没说 | 给数量或名字 |
| 绝美 / 震撼 / 不容错过 / 极致体验 | 销售话术 | 给可验证的事实 |
| 让我们一起 / 快来 / 你准备好了吗 | 公众号腔 | 删掉 |
| 建议您不妨 / 不妨一试 | 绕 | "建议……" |
| 需要注意的是 | 冗余 | "注意：" 或直接写 |

**emoji 只用于分类标记**（如专项图标、天气符号、优先级 🔴🟡），不用于强调语气。
一句话里最多一个。

## 二、句式禁令

1. **禁止三段式排比。** "看日出，看星空，看潮起潮落" → 挑最相关的说。
2. **禁止空洞总结句。** 每段结尾不要再来一句概括，读者刚看完不需要复述。
3. **禁止形容词堆叠。** 一个名词最多一个形容词，"美丽迷人的海滨城市" → "海滨城市"。
4. **禁止"我们"腔。** 方案是给用户的，不是替用户表态。"我们会去……" → "14:00 到……"。
5. **禁止假设用户已经知道背景。** 专业名词第一次出现要一句解释（如"干潮就是潮水最低的时候"）。
6. **句子别太长。** 超过 40 字就断。中文长句是 AI 味的重灾区。

## 三、该有的样子

### 1. 数字优先，形容词让位

可验证的数字是旅行方案最硬的东西。有数字就别用形容词。

- 差：这里交通便利，适合自驾前往。
- 好：从市区开车 40 分钟，停车场 30 个车位，节假日 8 点后基本满。

### 2. 写"做什么"，不写"多好"

用户需要动作指令，不需要评价。

- 差：成山头的日出非常壮观，令人心潮澎湃。
- 好：成山头朝东、无遮挡，10 月日出 05:53。05:20 前到占位，停车场走到观景台约 8 分钟。

### 3. 把风险写成条件句

安全提示要能直接执行，而不是抽象提醒。

- 差：赶海时请注意安全。
- 好：干潮 09:12，10:40 前必须离开滩涂。涨潮时水从潮沟灌进来，看着还浅其实已经过膝。

### 4. 说清不确定的部分

不知道就说不知道，并且告诉用户去哪儿能查到。这比编一个数字负责得多。

- 差：门票大约 100 元左右。
- 好：门票未查到 10 月旺季价（景区官网最近更新是 2026-03，写的是淡季 80 元）。出发前打 0631-XXXXXXX 确认。

### 5. 用短句，一句一件事

- 差：由于威海地处山东半岛东端，三面环海，因此气候受海洋调节明显，昼夜温差相对较小，
  同时由于纬度较高，秋季降温速度较快，所以需要准备保暖衣物。
- 好：威海三面环海，秋天昼夜温差小。但纬度偏北，10 月夜里能到 10℃ 以下，带件厚外套。

### 6. 专业名词就地解释

- 差：请根据波特尔分级选择合适的观测点。
- 好：找光污染 4 级以下的地方（波特尔分级 1-9 级，数字越小越黑，市区一般是 7-9 级）。

## 四、各模块的写法

| 模块 | 要点 | 反面 |
|---|---|---|
| 行程项 | 时间 + 地点 + 动作 + 一个关键提示 | 只写地点名，像打卡清单 |
| 美食推荐 | 人均价 + 为什么去 + 要不要排队 | "当地特色美食，值得一尝" |
| 自然专项 | 精确时刻 + 判断依据 + 数据源日期 | "风景很美，适合观星" |
| 踩坑提示 | 坑是什么 + 什么时候会遇到 + 怎么绕 | "注意安全，文明旅游" |
| 待办清单 | 渠道 + 截止日 + 没办成怎么办 | "请及时预订" |
| 备选方案 | 触发条件 + 换掉哪段 + 怎么接回 | "如遇天气原因可调整" |

## 五、交付前自检

文案写完后，逐条问自己：

1. **删掉这句，用户会少知道什么？** 答不上来就删。
2. **这句话里的数字，追得到来源吗？** 追不到就标估算或改成 `unknown`。
3. **把这段念出来，像人在说话吗？** 像报告就重写。

这三问过不了，就说明文案还在 AI 味里。

## 六、一个完整对照

**改前**

> 威海是一座风景优美的海滨城市，拥有丰富的自然与人文资源。本次行程精心规划，
> 力求为您打造一次难忘的海滨之旅。值得注意的是，10 月正是观鸟的黄金季节，
> 鸟类资源丰富多样。让我们一起去感受大自然的美好吧！
>
> 首先我们将前往观鸟胜地，其次体验赶海的乐趣，最后欣赏壮丽的日出，
> 相信这次旅行一定会给您留下美好的回忆。

**改后**

> 10 月是候鸟南迁的过境期，威海正好在迁飞通道上。荣成大天鹅保护区这几天记录到
> 黑嘴鸥、蛎鹬等水鸟（eBird 近 7 天观测，09-22 查）。
>
> 两天安排成这样：
> - D1 清晨观鸟，09:12 干潮前后赶海，夜里 22:30 后观星（当天娥眉月，照度 8%，暗夜条件好）
> - D2 05:53 日出，之后环海路骑行，15:08 高铁返程
>
> 唯一的硬约束是潮汐：赶海窗口只有 09:12 前后各一个半小时，错过就得等下一个潮期。

差别不在文采，在于**第二版里每一句都能被执行**。
