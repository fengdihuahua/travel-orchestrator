# UI / UE 设计规范

> 适用对象：`scripts/render_plan.py` 渲染出来的单文件 HTML 攻略
> 版本 v3.0.0 · 2026-09-22
> 样式实现：`assets/handbook.css`（渲染时内联进 HTML，保持单文件离线）

---

## 1. 设计上下文（先定这个，再谈样式）

没有上下文的设计一定泛化。这份攻略的上下文是固定的：

| 项 | 内容 |
|---|---|
| **读者** | 出发前要照着走的人。多数在手机上快速扫一遍，少数会打印一份带在身上 |
| **任务** | ① 30 秒判断"这趟靠不靠谱" ② 出发前照着清单办事 ③ 现场对着时间轴走 ④ 事后能核对数据出处 |
| **语气** | 热闹、有精神、少女感，不端着。像番剧封面，不像公司 PPT |
| **记忆点** | ① 弹幕条（封面底部飘过的关键词）② 四个自然专项的场景动效 ③ 满页会闪的小星星 |
| **使用场景约束** | 可能在地铁里单手翻、可能打印成黑白纸、可能用老人机看。所以：字号不能小、对比要够、打印要能读 |

**判断标准（反 AI 味）**：把这页给人看，如果说"这是 AI 做的"就说明失败。避免通用模板脸，居中大标题、青紫渐变、圆角卡片加柔光投影、标题上方一个大图标，这些都是模板特征。

## 2. 色彩

主色取自 B 站那对经典色：**弹幕粉 + 番剧蓝**；少女感靠一组扩展糖果色补，中性色全部往粉紫偏一点，不用纯黑纯白。

| 变量 | 值 | 用途 |
|---|---|---|
| `--bb-pink` | `#fb7299` | 主强调：章节图标、时间轴节点、日期徽章、返回顶部、勾选态装饰 |
| `--bb-pink-deep` | `#e5457a` | 粉色文字（链接、悬停态），保证白底上的对比度 |
| `--bb-pink-soft` | `#ffe9f1` | 粉色浅底：悬停背景、贴纸阴影 |
| `--bb-pink-mist` | `#fff6fa` | 更浅的粉：条目悬停底、备选块底、待办悬停底 |
| `--bb-blue` | `#00a1d6` | 次强调：偶数节图标、聚焦描边、勾选态、进度条终点 |
| `--bb-blue-deep` | `#0083ad` | 蓝色文字（时刻、日期、链接） |
| `--bb-blue-soft` | `#e3f6fd` | 蓝色浅底：卡片贴纸阴影、提示框 |
| `--bb-mint` | `#2bd6b5` | 第三色：自然专项要点条、状态「已核查」 |
| `--bb-lilac` | `#b48cf2` | 第四色：章节图标、D3 日期徽章、预算条中段 |
| `--bb-gold` | `#ffb01a` | 第五色：用餐标签、贴纸高光 |
| `--bb-peach` | `#ff9f7a` | 第六色：章节图标、警示边 |
| `--ink` / `--ink-2` / `--ink-3` / `--ink-4` | `#241f2b` / `#575060` / `#8b8495` / `#b8b2c2` | 正文 / 次要 / 辅助 / 更淡 |
| `--bg` | `#fdfaff` | 页面底（极浅粉白，不是纯白） |
| `--surface` | `#ffffff` | 卡片面 |
| `--stroke` / `--stroke-2` | `#ece4f0` / `#d6cbe0` | 描边（常态 / 悬停） |

**语义色**（只用于状态，不参与装饰）：警示橙 `#ff7a45`、阻断红 `#c7163c`、通过绿 `#0f7a5f`、估算黄 `#8a6a12`。

**用法规则**
- 六个强调色按**章节循环**分配（`.sec:nth-of-type(6n+k)`），一屏之内不出现三种以上同权重强调。
- 小面积用色：图标、节点、徽章、按钮；大面积只出现在封面。
- 文字不用 `--bb-pink`（对比度不够），粉色文字一律 `--bb-pink-deep`。
- 状态徽章要压在封面渐变上，底色必须够深：`draft/conditional` 用 `#d6226b`、`executable` 用 `#0f7a5f`。

**禁止**：纯黑 `#000` / 纯白 `#fff` 当背景；青紫渐变当主视觉；霓虹光晕；毛玻璃堆叠；无意义火花线。

## 3. 排版

**字体只用系统圆体栈**，离线单文件不能引字库，所以拉丁优先命中圆体（Varela Round / Quicksand），中文依次尝试系统圆体（圆体-简 / 幼圆）再回退黑体。

| 角色 | 字体栈 | 用法 |
|---|---|---|
| 正文 | `--font-sans`（圆体优先，回退系统中文黑体） | 15px / 行高 1.78 |
| 标题 | `--font-display`（同栈，字重 900） | 封面 h1 `clamp(26px,4.6vw,38px)`；章节 h2 23px；卡片 h4 17px |
| 数字 | `--font-num`（Quicksand / Bahnschrift） | 时刻、金额、日期、数量、徽章编号 |

字号阶梯固定为：38 / 23 / 17 / 16.5 / 15 / 14 / 13.5 / 13 / 12.5 / 11.5（px）。不新增中间档。

**规则**
- 圆体字面方，标题**不用负字距**（`letter-spacing` 用 0 到 +0.2px 反而更透气）。
- 数字一律走 `--font-num`，正文里混排不跳。
- 不用花体、不用书法体（打印会糊、低端设备会缺字）。

## 4. 布局与间距

- 内容宽度 940px，两侧留 18px；正文行宽控制在中文 30-38 字。
- 垂直节奏：章节之间 50px，卡片之间 12-14px，段落内 8px。
- 网格用 `repeat(auto-fit,minmax(190px,1fr))`，窄屏自动降列，不做断点魔法。
- **唯一例外**：自然观察专项**每个专项占满一整行**（见 §5），不再用大小不一的宫格。
- 断点只有一个：`max-width:680px`（自然专项卡由"左图右文"转"上图下文"、依据表表头允许折行）。

## 5. 图形语言（描边贴纸 × 布灵布灵）

统一的三句话：**1.5px 描边 · 同色系实心偏移 · 直角感的小方块点缀**。

| 元素 | 做法 |
|---|---|
| 卡片 | `border:1.5px solid var(--stroke)` + `box-shadow:3px 3px 0 var(--bb-blue-soft)`（实心偏移，不是柔光投影）；悬停时偏移换粉、上移 2px |
| 网格格子 | 同上，偏移 2px；右上角一个 7px 粉色小方块当锚点 |
| 章节图标 | 内联 SVG，`viewBox="0 0 24 24"`，`stroke-width="1.9"`，装在一块 32px 的歪色牌（`rotate(-3deg)`）里，六色循环 |
| 小贴图 | 内联 SVG，`viewBox="0 0 32 32"`，糖果色填充 + `#e5457a`/`#12836b` 一类深色描边，`drop-shadow(1.5px 2px 0 rgba(0,0,0,.06))`，静止时缓慢浮动 |
| 时间轴节点 | 12px 圆角方块（不是圆），悬停旋转 45° |
| 标签 | 描边胶囊：`border:1px solid currentColor` + 同色系浅底，不用实心色块 |
| 场景头图 | 整行卡的左侧竖条 216px 宽，**右侧**剪出 18px 一个的扇形缺口；窄屏转成 112px 高、缺口在底边 |
| 弹幕条 | 封面底部 26px 高，5 个半透明白胶囊横向飘过 |

**小贴图放哪（不多不少）**

| 位置 | 数量 | 说明 |
|---|---|---|
| 封面右上 | 3 枚 | 贝壳 / 小鸟 / 蝴蝶结，错峰浮动 |
| 每个章节标题右端 | 1 枚 | 心 / 云 / 叶 / 相机 / 奶茶 / 硬币 / 星 / 路锥 / 地图针，与图标色错开 |
| 每张自然专项卡 | 1 枚 | 贴在场景图右下角，与专项主题对应 |
| 封面上 | 5 颗珠光星点 | 白色四角星，错峰缩放闪烁 |

**背景（布灵布灵三层，全部用渐变画，不引图片）**

1. **底色层**（`body`）：`--bg` 浅粉白 + 115° 斜纹带（alpha .06）+ 18px 圆点阵列。
2. **柔光层**（`body::before`，`z-index:-1`）：五团彩色径向柔光（粉 / 蓝 / 紫 / 薄荷 / 柠檬），34s 缓慢位移缩放（`aura`）。负 z 层保证永远压不到内容。
3. **闪光层**（`body::after`，`z-index:-1`）：极淡的白色斜纹，7s 呼吸（`shimmer`）。
4. **星点层**（`.bling`，12 颗 `<i>`，`z-index:-1`）：四角星用 `clip-path` 画，各自错峰闪烁（`bling`，5.2s），颜色在粉 / 蓝 / 金 / 紫 / 薄荷间轮换。

> 星点集中在页面四边，中间区域少放，避免压住正文阅读。

## 6. 动效

**总原则**：缓动统一 `cubic-bezier(.25,1,.5,1)`（ease-out-quart），收得干净不回弹；只做**状态变化**和**环境氛围**，不做入场表演。

| 类型 | 时长 | 说明 |
|---|---|---|
| 状态变化（悬停/聚焦/展开） | 180-250ms | 位移 ≤ 3px，阴影偏移 2px |
| 环境动效（场景头图、弹幕、柔光、星点） | 3.2-41s 循环 | 幅度小、速度慢，扫过去不抢注意力 |

**四个自然专项的场景动效**

| 专项 | 画面 | 动效 |
|---|---|---|
| 观星 | 夜蓝渐变 + 月亮 | 8 颗星错峰闪烁（3.2s）、月亮上下浮 5px（11s） |
| 赶海 | 番剧蓝渐变 | 三层浪不同速度横向漂移（8.5/11/13s）、贝壳上下浮 |
| 观鸟 | 薄荷绿渐变 + 芦苇 | 两只鸟扇翅掠过（15/19s）、芦苇摇摆（4.6-6.4s） |
| 日出 | 粉金渐变 + 光芒 | 太阳呼吸式升降（10s）、光芒旋转（26s）、云横移 |
| 朝晚霞 | 粉橙→紫渐变 | 三条霞光带通透移（12/15/18s） |

**硬约束**
- 必须给 `@media (prefers-reduced-motion: reduce)` 全部关掉（星点降为常亮 50%）。
- 打印时一律 `animation:none`，装饰层 `display:none`。
- 不动画化布局属性（只动 `transform` / `opacity` / `background-color`）。

## 7. UE · 信息架构

九节固定顺序，逻辑是**先 30 秒看懂全局 → 再给可执行细节 → 最后交底**：

```
① 一页速览        ← 目的地/出发地/同行/预算/节奏/专项，看这一屏就够
② 天气研判        ← 逐日天气 + 会影响什么
③ 自然观察专项    ← 观鸟/观星/日出/赶海/朝晚霞，一项一整行；带图表的卡走通栏（上动效下内容）
④ 逐日行程        ← 日期锚点条 + 每天可折叠的时间轴，含备选
⑤ 美食推荐        ← 去哪吃、吃什么、多少钱
⑥ 预算明细        ← 分项区间 + 合计 + 超支提示
⑦ 出发前待办      ← 要提前办的事，可勾选，带截止与"没办成怎么办"
⑧ 踩坑指南        ← 已经踩过的坑 + 怎么绕
⑨ 依据索引        ← 每条结论追到来源与取数日期（来源清单默认折叠，网址可点）
```

**三条阅读动线**（对应三类读者）
1. **决策动线**：封面 → 速览 → 天气。只想知道"去不去"的人到这就够。
2. **执行动线**：逐日行程 → 出发前待办 → 美食。准备出发的人走这条。
3. **质疑动线**：踩坑指南 → 依据索引。不信任 AI 的人走这条，能查到每一个数字的出处。

**归档不入册**：红方复核（`scripts/red_team.py`）是生成过程里的质量门，属于过程记录，**不写进交付物**。复核中未解决、读者必须知道的风险，改写进「踩坑指南」。

## 8. 交互（能点的东西）

全部用 HTML + CSS 实现，**不引入任何脚本**（离线单文件的底线）。

| 交互 | 实现 | 状态反馈 |
|---|---|---|
| 章节跳转 | 顶部吸顶导航 `<nav class="toc">` 锚点 | 悬停上移 2px + 粉底，小方块转 45°；跳转后 `:target` 用粉底标出落点 |
| 跨天跳转 | 逐日行程顶部的**日期锚点条** `<a href="#day-D1">` | 悬停浮起、粉边；跳过去后该天卡片整块高亮 |
| 收起某一天 | 每天一个 `<details class="day" open>` | 默认展开；summary 前的方块转 135°；折叠状态由浏览器记 |
| 地点查地图 | 每个地点渲染成 `<a class="map" href="https://uri.amap.com/search?keyword=…">` | 虚线下划 + 右上箭头；新窗口打开，页面本身不联网 |
| 勾掉待办 | 真 `<input type="checkbox">`（纯 HTML） | 勾上变蓝底白勾、文字划线变灰；状态不落盘，刷新即还原 |
| 核对来源 | 来源清单 `<details>` 默认折叠；网址是真链接 | 展开时边框转粉、小方块转 135°；链接悬停转粉 |
| 回到顶部 | 右下角固定按钮，锚到 `#top` | 悬停变蓝、上移 3px 并轻微旋转 |
| 卡片/条目悬停 | CSS `:hover` | 卡片上移 2px、偏移阴影换粉；时间轴条目淡粉底 + 右移 2px |

**可访问性**
- 所有可聚焦元素有 `:focus-visible` 描边（2px 蓝，偏移 2-3px）。
- 纯装饰元素（图标、贴纸、弹幕条、星点层、场景图形）加 `aria-hidden="true"`。
- 锚点跳转设 `scroll-margin-top:70px`，标题与当天卡片不被吸顶导航盖住。
- 正文对比度 ≥ 7:1（`#241f2b` on `#fdfaff`）；粉色只用于图形与大字号。
- 语义标签：每节一个 `<section id>`，导航用 `<nav aria-label>`。

### 8.1 自然专项的四个交互件

代码在 `scripts/nature_widgets.py`。四件东西的设计口径：

| 交互件 | 交互方式 | 为什么这么设计 |
|---|---|---|
| **鸟种卡** | `<details>`：收起一行（剪影 + 中名 + 学名 + 保护等级徽章），展开看分类/简介/来源与四枚外链 | 一页可能有十几种鸟，全展开是墙；收起态就够"这只叫什么、危不危险"。剪影按类群自动选，颜色走六色循环 |
| **示意星图** | 悬停任一星点出 `<title>` 提示（高度/方位/星等） | 星图上标注多了必糊；把精度放进悬停提示，纸面保持干净 |
| **天光条** | 无点击；蓝调/黄金/白昼/夜间一条横轴看全，日出日落刻度带时刻 | 时间类信息用位置表达比用文字快；窄段放不下字就给色块图例 |
| **潮汐点选** | 点曲线上的圆点 → 下方面板换成该时刻的潮位与下滩建议，默认选中干潮 | 赶海的安全判断是"那个时刻我能不能下去"，不是"最低潮几点"，所以按时刻点选而不是给结论 |

**潮汐点选的实现要点**（纯 CSS 无脚本，但有个坑必须记住）：
- 结构：`.tide` 里依次是 N 个 `<input type="radio" class="tp">`、`.tide-plot`（内含 SVG 与 `.tp-marks` 圆点层）、`.tp-panels`（N 块面板）
- 选中规则：`.tp:nth-of-type(k):checked ~ .tp-panels > .tp-panel:nth-child(k)`
- ⚠️ **只写 `.tp:checked ~` 是错的**：`~` 只问"前面有没有被选中的单选框"，不关心是第几个，
  于是 32 条选择器会全部命中，所有面板一起显示。必须用 `:nth-of-type(k)` 把序号钉住
- 圆点用绝对定位盖在 SVG 上（`left/top` 按数据算成百分比）；上限 32 个点，超了在渲染层抽稀
- 单选框本体 `opacity:0` 但不 `display:none`，键盘仍可 Tab 到，`focus-visible` 时给对应圆点描边

**星图的口径（写进页面，别让人误当精密星历）**：
- 内置 43 颗亮星（J2000）+ 6 组星群连线；算法：儒略日 → 格林尼治恒星时 → 地方恒星时 → 时角 → 高度/方位
- 只画地平线以上（alt > 0.4°）的星；星点半径 `3.9 - 0.42×星等`；方位从正北起顺时针，高度映射到半径
- 标签避让：星群名先占位并往图外推 30px、再压回圆环内侧 0.84R；亮星（星等 ≤1.7 且 alt >7°）标签
  逐个检查与已占位的距离，太挤就放弃那一个
- 文字都带 `paint-order:stroke` 的深色描边晕，压在星点上也不糊
- 月亮盘按真实照度画终结线：椭圆半轴 `rx = R·|2k-1|`，`k<0.5` 时扫掠方向取 1、`k>0.5` 取 0

**这四个交互件上线后返修过一轮，下面几条是踩出来的硬规则：**

| 规则 | 为什么 |
|---|---|
| 地点串用 `.pl{display:flex;flex-wrap:wrap}`，分隔符由 `.pl-item+.pl-item::before` 生成，**不要写进 HTML** | 写成文本节点的话，一行排不下时「、」会孤零零落在行尾；CSS 生成的永远跟着后一项 |
| `.pl-item{flex:0 1 auto;max-width:100%}` | `0 0 auto` 时单个超长地名会溢出；`0 1 auto` 让「地名+备注」平时是整体换行单元，真放不下才内部折行 |
| 地点行（观察点/观测点/地点）用 `wide` 整行通栏 `.kv.wide{grid-column:1/-1}` | auto-fit 出来的 1/3 列只有 270px，长地名会被拆得七零八落 |
| 通栏卡的要点网格用 `.card.tall .dl{minmax(300px,1fr)}`，不要沿用 230px 的三列 | 「注意」这种长值挤在 270px 里会挤出四五行的窄筒，右边还空一整列 |
| 星图行两列 `minmax(0,1.15fr) minmax(0,1fr)`，月相盘与「今晚看什么」同列 | 原来右列写死 140px，星图居中在 1fr 里，正文两侧各空 150px，像没排完 |
| 通栏卡场景变横带后，标签改半透明深色胶囊；场景里的图形元素（如观鸟的芦苇丛）要让开标签位置 | 横带底色比竖条浅、标签又落在最深的一段，白字压上去读不清；芦苇丛原本贴左边，正好压在标签下面 |
| 打印时把通栏横带压到 38px，**必须同时写 `height` 和 `min-height:0`** | 通栏卡的 `.scene` 有 `min-height:118px`，优先级和打印规则一样，只设 `height` 会被 `min-height` 顶回去，横带还是 118px |
| 打印标签用白底描边的印刷小签 | 场景底色从浅薄荷到深藏蓝都有，纯白字或纯黑字总有一种底色上读不清 |

**验收手法**（本机没装 agent-browser，用 `tools/` 里的两个小工具）：

```bash
python tools/shot.py  <html> --measure ".nature,.skychart" --offsets 1000,2000
python tools/shot.py  <html> --print --offsets 760      # 核对打印版式
python tools/probe.py <html> --root ".skyrow"           # 列出盒模型/display，定位错位元素
```

- Chrome 命令行**不吃相对路径**，`--screenshot=` 必须给绝对路径，否则静默不写文件
- Chrome 命令行**不能选 print 媒体**，`--print` 的做法是把 HTML 里的 `@media print`
  临时换成 `@media all`
- 低分辨率截图容易看错行（把同一行的两项看成两行），**以 `probe.py` 的坐标为准**，
  同一 `top` 就是同一行
- 别在 `querySelector` 里传不带引号的选择器；语法错误会让整个 `<script>` 块不执行，
  表现是"脚本没跑"，很容易误判

## 9. 打印

`@media print` 下把屏幕语言全部收掉，只留内容：

- 封面转白底 + 3px 粉色下边线，去渐变去弹幕去星点。
- 导航、日期锚点条、返回顶部、弹幕条、星点层、所有小贴图 `display:none`。
- 所有偏移阴影、悬停位移、图块旋转取消；描边转灰。
- 折叠与"每天一卡"全部展开（打印纸上点不开），`<details>`/`.dbody` 强制 `display:block`。
  ⚠️ 鸟种卡也要展开，但**只覆盖 `.sp-body` 的 `display` 已经不够**：Chromium 131+ 用
  `::details-content` 的 `content-visibility` 控制折叠内容的可见性，必须同时写
  `.sp::details-content{content-visibility:visible;block-size:auto}`（老引擎认 `display:block` 那条）
- 星图反白：夜空底转白、星点转深、星群名/星名去掉深色描边晕；月亮盘与月亮标签转浅色底
- 天光条与潮汐图限宽 520px，不让大面积色块吃墨
- 卡片 `break-inside:avoid`，标题 `break-after:avoid`。
- 场景头图压到 38px（通栏卡）/ 44px（普通卡）、降饱和，避免吃墨；
  横带里 48~64px 高的场景图形（芦苇丛之类）会被切一半，直接不画。
- 场景标签改成白底描边小签，横带底色从浅薄荷到深藏蓝都有，纯白或纯黑字总有一种读不清。
