# AI 一层绘制海报

实现：`scripts/poster_ai.py`。产出是一张 AI 生成的 A4 竖幅图（1024x1536），可打印、单文件。

    python scripts/poster_ai.py <行程目录> --day 1 --out _tmp/ai

产出 `sketch.png`（骨架草图）、`prompt.txt`（生图提示词）、`meta.json`。把骨架当底稿交给图像模型，
`input_fidelity="high"`，`prompt` 取 `prompt.txt` 全文，`size="1024x1536"`（不传会出方图）。
最后切掉底部 4.5% 的 AI 水印。骨架是一次性底稿，不进成品。

## 两种生成模式

    骨架版（默认）：python scripts/poster_ai.py <目录> --day 2 --out _tmp/ai
    纯文字版：      python scripts/poster_ai.py <目录> --day 2 --out _tmp/ai --plain

| | 骨架版 | 纯文字版（`--plain`） |
|---|---|---|
| 生图怎么传 | `image1=sketch.png` + `prompt.txt` 全文 | **只给 `prompt.txt`** |
| 位置靠什么定 | 骨架上的红点 + 框，提示词里再补九宫格 | 全写在话里：九宫格 + 与近邻的相对方位 |
| 实测（东营 D2，5 个点） | 位置**错 4/5**、地名串 2 个 | 位置**全对**、地名 4/5 对 |

**两条路都要把位置写进提示词**（`pos_lines`：九宫格 + 相对方位）—— 只靠骨架图，模型会把标签
重新摆一遍。之所以还留着骨架版：地形区块（海在哪一侧、岸线走向）画在图上比写文字更直观。
`--plain` 那份提示词自包含，**不引用任何图片**。

**拿到图先过一道机器门，别靠肉眼**：

    python scripts/poster_check.py <生成的图.png>

生图接口**会偶发返回一张近乎空白的图，却仍然报成功**（实测遇到一次：标准差 2.7、
采样色数 81，正常图是 40-57 / 2700-5700）。空白图直接交付等于白跑一趟，所以判不合格就重新生成。

## 规矩

1. **成品只有一张图**，不叠代码文字层。叠上去的字和底图对不上。
2. **骨架图上不写字**，一个地点一枚小红点。文字与画法说明全在提示词里。
3. **画面里不出现任何序号**。一行就是「地名 ｜ 时段 ｜ 一句详情」（`东八路湿地观景台 ｜ 05:00-06:30 ｜ 鸟浪清晨场`），
   读者按地名对号。模型画数字不可靠——会漏、会重复、会串位、会糊成一团，索性不编号。
4. **同坐标 = 同一个地点**。行程里同一地点常写成不同名字（`东营市区`/`东营市区东城`、
   `黄河口生态旅游区南门`/`远望楼码头`），先按坐标并成一个点，再把这个地点的文字并到一处。
   代表名取最通用的那个（是其它名字前缀的优先）。**不并的话这些点会被去重叠工序推开成两个点**。
5. **任意两地之间的东南西北要和真实经纬度一致**，这是硬指标。
6. **不要求比例**，距离可调。
7. **均匀分布是手段不是目的**。目的是画面和谐、图和文字都占得下，不能为了均匀把方位搞错。
8. **不写死角度**，没有固定角度槽位，也不用排序位次法铺点。
9. **生图必传 size**，漏了就出方图。
10. **一张图最多 8 个点**（`MAX_POINTS`，`--max-points` 可改，0 = 不设上限）。超了就合并：
    每次挑**真位最近的一对**并成一个点（最近的一对本来就常是同一片地方），名字留更重要的那个
    （带鸟浪/赶海/日出…这类体验词的优先），文字并到一处、仍最多两行，坐标取成员中点。
    谁并进了谁记在 `meta.json` 的 `merged` 里。
11. **地名位只写地名**（朱红框）；行程（时段 + 详情）**一个地点最多两行**，全部集中成一块
    小字写在画面最空的那一大片里。海报是导览，不是把行程流水抄一遍；含鸟浪/赶海/日出/游船
    这类体验词的优先，纯赶路与休整排最后。两块文字里都**不带序号**。
12. **地形：海侧标「海」、陆侧标「山」「林」**。海侧方位由含水地点的真实方位推出；
    岸线横穿整幅，陆地与海两块**都以岸线为界**拼满画布（不许留大片空白纸）。
    名字以 镇/村/路/站 结尾的是「地方」不是水（`_PLACE_SUFFIX`），别把「孤岛镇」「环海路」
    当成水面。
13. **地名要防串字**。提示词里每个地名**逐字列出来**（`name_spell_lines`，写成「孤、东、海、堤」），
    并自动挑出**易混地名对**逐个提醒「各写各的」（`confusable_notes`：共字 ≥2 个 / 首字相同 /
    共用一个只属于这两个名字的字）。⚠️ **反面例子不要写进提示词**（写了它会照抄那个错样子）。
    实测踩过：「孤东海堤」被写成「孤岛海堤」，借了「河口区孤岛镇」里的「岛」。
    最后一道防线是**交付前读图核对**：把成品图和 `meta.json` 的 `names` 逐个对一遍，
    串字就重生成 —— 这一步没有机器能替。
14. **交付前跑 `scripts/poster_check.py`**：空白图、尺寸不对的一律打回重生成。
15. **长地名用「海报显示名」**：把「生态旅游区 / 自然保护区 / 景区 / 公园」这类通用后缀去掉
    （`display_name`，剩 ≥2 字才削；重名就整体作废）。实测 8 字的「黄河口生态旅游区」
    被写成「黄河口生态游游」，4 字的地名全对 —— **字越少越不容易串**。
    全名仍在攻略页与 `meta.json` 里，映射记在 `display_names`。
16. **题签那几行小字要横排、要看得清**：整体竖排没问题，但亮点行必须横着写、
    字号只比副题小一点（实测缩成竖排小字后完全读不出来）。句子也压到 ≤14 字。
17. **路线顺序写死成一条链**（`route_chain`：`A → B → C`）。只说「按上面顺序串起来」
    模型会自己重排，画出来的走向和行程顺序对不上。顺序 = 当天各点第一次出现的先后。
18. **出图后逐字对比，这是流程里的一步**：`poster_ai.py` 会写 `checklist.txt`
    （地名逐字、题签逐字、行程逐行），照着它对成品一个一个字看；
    **有一处不对就重生成**（读图就能对，不需要 OCR）。提示词只能降低概率，
    真正兜底的是这一步。
19. **行程那一块要按「整块矩形」找位置，并且避开路线**（`text_block_spot`）。
    以前只按一个点算空处，块一摊开就压到点、框或路线上（实测块到路线相交 21px）；
    现在按块的实际尺寸（宽 520、高随行数）算矩形间距，并把**相邻点之间的连线走廊**
    （`route_corridor`）也当障碍。块高是关键：520×454 在一天 9 行的画面上找不到
    完全空处，压到 520×342 才让得开。
20. **提示词要压到 2000 字以内**（2026-10-14 甲方要求，因为要拿去别的生图模型试）：
    超了就删**重复表述**，不要删防线。当前纯文字版约 1610 字、骨架版约 1998 字，
    `run_tests.py` 有断言守着。压缩时优先砍「同一要求的第二种说法」；
    骨架版里与骨架图重复的地形铺陈也可以让给图去交代。
    断言点名要的短语不能少：`不许出现任何序号数字`、`只准出现下面列出的文字`、
    `已经用淡墨写着这个地点的名字`、`标方位的几个小字`+`成品里不要写`、
    `只写那个地点的名字`+`不要写时间、不要写任何描述`+`只写这几个字：X`、
    `全部集中写在一处`、`只写一次`+`不要拆开`、`每个点在画面的哪个位置`+`放错了整张作废`、
    `不许把两个地名对调`、`地名逐字回读`。

## 点位怎么摆

`poster_ai.arrange`，四步，全部由数据推出。

1. 真位相距不到画布对角线 8.5% 的点并成一簇，也就是同一片地方。
2. 簇内保留各自的相对偏移，整簇等比放大，倍数 `k = min(3, 380 / 簇内最大间距)`。
   等比缩放，所以簇内相对方位不会错。
3. 每簇和每个孤立点当一个圆盘：角度用簇心的真实方位，半径用画布适配椭圆减去圆盘半径。
   点因此铺满整幅，不会挤在一角。
4. 逐对检查方位。真实差距明显、放置后符号相反的，沿该轴推开复位。

跑完自检，必须「错 0 项」才进生图：

    两两方位自检：<N> 项，错 0 项 ✅

## 每个点上放什么

- 一枚小红点（半径 18px 的朱砂圆），**不带数字**。
- 一个蓝色虚线框：小景画这里，框内不写字。
- 一个朱红虚线框：**只写这个地点的名字**，不写时间、不写描述（框比蓝框矮一行）。
- 行程（时段 + 详情）**不占框**：全部行集中成一块小字，写在画面最空的那一大片里
  （`text_block_spot` 用最大空圆找位置，提示词按方位点名）。字号比地名小一点。

小景要精细、有细节、五到六幅大小相当、笔触松弛有飞白。不要矢量描边、纯白剪贴、卡通、素材库图标。

提示词只给「这里画什么」一句话，由地点名的关键词规则生成。不给图标库，不给固定清单——
预设图标会限制模型的发挥。

## 画面风格

- 暖宣纸底 `#f8f3e6`，写意不写实。矿物色只用花青、朱砂、藤黄、胭脂。
- 连线要有：淡墨手绘点线，断续小墨点，由浓到淡，像古地图的行旅路引。不要实线、等宽、蓝色、箭头。
- 文字要毛笔手写感，不要印刷体。
- 海岸线不能是一条硬边，要有沙滩、浅滩沙洲、渐变水色过渡。
- 地形只交代山、林、湖、海，不画精确海岸线，成品里也不许出现这几个字。
- 不要水印、logo、罗盘、图例、比例尺、边框。

## 模型的硬限制

| 限制 | 对策 |
|---|---|
| 多行小字分配不可靠，会漏、会重复、会把 A 的文字配到 B 的点上 | 骨架不写数字；提示词按「「地名」那个红点旁」逐条点名，并把「照抄、每行只写一次」列为硬约束 |
| 画数字更不可靠（会把序号写乱、写重、写糊） | **画面里一个序号都不写**，文字行只写「地名 ｜ 时段 ｜ 详情」，读者按地名对号 |
| 画面上多写字就变小糊掉 | 一个地点最多两行，全图小字数量在提示词里写明，并要求「字写大一些」 |
| 会认错抽象简笔画（实测把贝壳认成天鹅，两个小景被调换） | 骨架不用简笔画承载语义，语义全写提示词 |
| 会把虚线框当成给它的说明，不画进成品 | 可放心用虚线框做标注 |
| 会照抄骨架上的方位提示字（「山」「林」被画进成品） | 提示词里**不要出现这几个字**，改说「角上那两个小字只是标方位，成品里不要写」 |

## 不要这么做

这些做法都试过，会出问题：

- AI 画景 + 代码叠文字：字和底图对不上
- 骨架里写文字说明，或红框内写具体文字：模型会漏、会重复、会把文字配到别的点上
- 骨架里画抽象简笔画表示「这里画什么」：模型会认错（把贝壳认成天鹅）
- 按坐标排序铺位次：会破坏方位
- 写死角度槽位：方位会失真
- 只要求「方位大致一致」：不算达标
- 取消连线：看不出先后顺序
- 满幅 AI 水墨底图压住点位：画面又空又脏
- 给点位预设图标库或语义选图：限制模型发挥
- 在画面上写序号（无论写在红点上还是写在文字行首）：模型会漏、会重复、会串位；
  写成几行小数字更糟，越写越小越糊
- 为了把序号编齐而把一个地点的每次出现都列成一行：一天十几行小字，模型直接合并、漏行
- 骨架里只标「山」「林」两个方位字、**不标「海」**：整幅图里没有「海」这个字，
  模型就自己猜海画在哪（实测把海画到了北边，而真实海岸在东侧）
- 海岸线只在中心取几个像素宽：沙滩画成一个圆斑、海面细成一条缝，整张骨架上看不见海
- 陆地用「四个角都在画布外的矩形」再去逐角 clamp：两个角会塌到同一个画布角上，
  边界变成一条 45° 的假斜线，左上还留一大片空白纸（提示词却写着不许留空白）
- **给小景配真实照片当参考图**（`--refs`）：试过一版，模型会把照片**整块贴进画面**，
  直接破坏「成品是一张水墨图」。甲方原话：「参考图明显多此一举，只会带来错觉」。已删掉这条功能。
- **只把位置画在骨架图上、不在提示词里写死**：模型会按自己的构图把标签重新摆一遍
  （实测 5 个点错 4 个）。位置必须两边都写。
